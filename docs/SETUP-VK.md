# Настройка VK Рекламы

VK подключать необязательно: сервис работает и с одним Директом. Если подключены обе площадки, бюджет делится 70/30 в пользу Директа и перераспределяется по цене обращения ([RULES.md](RULES.md)). Адаптер VK написан по документации и проверен только на симуляторе и тестах с подставленными ответами, на живом кабинете его ещё нужно прогнать ([LIMITATIONS.md](LIMITATIONS.md)).

## 1. Кабинет и доступ к API

1. Создайте рекламный кабинет на https://ads.vk.com и заполните данные рекламодателя (для юрлиц они проходят модерацию).
2. В кабинете откройте «Настройки» → «Доступ к API» → «Запросить доступ». Укажите ФИО и контакты ответственного. Срок рассмотрения VK не называет. Вопросы по доступу: ads_api@vk.team.
3. После одобрения в том же разделе создаются данные приложения: `client_id` и `client_secret`. Секрет показывается один раз и ограниченное время (по справке VK около 10 минут), повторно не выдаётся: сразу сохраните его.

## 2. Два способа подключить кабинет пользователя

### Вход через VK (`authorization_code`)

Пользователь нажимает «Подключить ВКонтакте» в сервисе, подтверждает доступ на странице VK Рекламы, и сервис получает токен. VK выдаёт такой доступ для сторонних пользователей «при выполнении условий», которые в документации не раскрыты. Если VK не включил этот режим для вашего приложения, используйте ключ.

Что нужно:

1. В приложении VK Рекламы укажите redirect URI:

   ```
   https://<домен>/api/auth/vk/callback
   ```

   Он строится из `APP_BASE_URL` (`backend/app/auth/vk.py`, `backend/app/api/vk.py`) и должен совпадать с ним точно.
2. Запрошенные права: `read_ads`, `create_ads`, `read_payments`.
3. В `.env`:

   ```
   VK_CLIENT_ID=<client_id приложения>
   VK_CLIENT_SECRET=<client_secret приложения>
   ```

   и перезапустите `api` и `worker`: `docker compose --env-file .env -f deploy/docker-compose.yml up -d`. Секрет нужен и для обновления токенов: access-токен VK живёт 24 часа.

Без `VK_CLIENT_ID` кнопка входа через VK отвечает «Подключение VK пока не настроено. Используйте ключ API».

### Ключ (`client_id` и `client_secret`)

Способ для случая, когда у пользователя есть своё приложение в «Доступ к API» (в том числе когда VK не дал сервису режим `authorization_code`). На странице подключения VK («Подключить по ключу») пользователь вводит `client_id` и `client_secret` своего кабинета. Сервис получает токен по схеме `client_credentials`, проверяет его запросом профиля и сохраняет. Ключ шифруется (`TOKEN_ENCRYPTION_KEY`) и хранится вместе с токеном для его обновления; в браузере он не сохраняется. Для этого способа `VK_CLIENT_ID` и `VK_CLIENT_SECRET` в `.env` не нужны.

Пароль от кабинета сервис не запрашивает ни в одном из способов.

## 3. Ограничения VK

- Не более 5 токенов на связку «приложение плюс пользователь»; при превышении VK отвечает 403, сервис сообщает «У VK достигнут предел в 5 токенов для этой связки». Не подключайте кабинет по ключу многократно подряд.
- Лимиты запросов VK приходят в заголовках `X-RateLimit-*`; сервис читает их и при исчерпании ждёт сброса.
- Отзыв токена у VK при отключении кабинета и удалении аккаунта не делается: сервис стирает токен у себя, но на стороне VK он остаётся действующим до истечения.

## 4. Параметры плана (`package_id`)

Создание плана в VK принимает необязательный `package_id` (пакет формата, перечень в методе `packages.json`). Сервис сейчас его не задаёт: адаптер умеет передавать значение, но в настройках оно не выводится. При создании плана используются цель `site_conversions` и стратегия `max_goals` (`API_FORMAT` в `backend/app/platforms/vk.py`). Если VK при первом запуске потребует `package_id` или отвергнет эти значения, это нужно выяснить на живом кабинете (список мест с допущениями: [LIMITATIONS.md](LIMITATIONS.md)).

## 5. Маркировка

Для VK данные рекламодателя вводятся в ОРД в кабинете: «Настройки» → «Маркировка рекламы». Для физлиц и самозанятых сервис передаёт имя, телефон и ИНН методом `ord_user.json`. Для юрлиц и ИП показывает инструкцию заполнить данные вручную и подтвердить это в сервисе. Токены креативов назначает VK. Объявления не включаются, пока маркировка не подтверждена.
