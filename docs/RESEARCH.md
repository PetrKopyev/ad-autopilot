# Исследование (этап 1)

Черновик. Факты о площадках и законах проверены 26.10.2026 по официальной документации и свежим публикациям; всё, что не удалось подтвердить, помечено «не подтверждено». Полный свод со ссылками: `docs/internal/research-platforms.md`.

## 1. Пользователь и его боль

Владелец салона, студии, йога-зала. Реклама для него — не работа, а повинность рядом с основной.

- **Нет времени и знаний.** Ставки, ключевые фразы, цели, счётчики, кабинеты нескольких площадок — отдельная профессия.
- **Страх слить деньги.** Бюджет небольшой, каждая потеря заметна. Отсюда требования: потолок, который не превышается, остановка всего одной кнопкой, любое изменение можно отменить.
- **Непонятно, окупилось ли.** Кабинет показывает показы и клики, а владельцу нужны обращения и клиенты. Клиентов система сама не видит, поэтому раз в неделю спрашиваем: «сколько из N обращений стали клиентами».

Следствие для продукта: меньше решений, у каждого действия есть объяснение простыми словами, цифры без выдумок («данные за последние дни неполные», «пока мало данных, решение не принимаем»).

## 4. Что сознательно не делаем и почему

Срок 7–10 дней и боевые деньги пользователя: лучше сделать меньше и надёжно.

- **Оплату и пополнение кабинетов** — деньги остаются у владельца в кабинете площадки. Если денег не хватает, сервис говорит об этом и продолжает после пополнения.
- **Автоматическое повышение общего бюджета** — потолок всегда решение владельца. Сервис лишь показывает карточку «можно получить больше обращений при бюджете выше».
- **Оценку цены клиента моделью** — только ответ владельца. Иначе в интерфейсе окажутся выдуманные цифры.
- **Playwright в проде** — потребовал бы пароли от кабинетов и ломается при смене вёрстки. Что недоступно через API (документы на модерацию, пополнение), сервис объясняет пошаговой инструкцией.
- **Посредников (Click.ru, eLama)** — запрещены заданием; **вход через Google** — не подходит под 406-ФЗ.
- **Роли и доступы, агентские кабинеты, несколько бизнесов на одного пользователя в интерфейсе** — вне объёма срока (в модели данных несколько бизнесов возможны).
- **Работу без сайта** — без сайта со счётчиком Метрики сервис не видит обращений и работал бы вслепую; вынесено в «что дальше».
- **SEO, соцсети, ретаргетинг, мобильное приложение, редактор креативов сверх текста и картинки, отдельный ML-прогнозатор** — вне фокуса задачи; решения принимает проверяемый код с понятными порогами.
